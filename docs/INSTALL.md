# 安装与开始使用

## 下载前

- macOS 14 或更新版本。
- 本次 DMG 为 **Apple Silicon（M 系列）arm64** 版本，不适用于 Intel Mac。Intel 源码构建方式见[开发指南](DEVELOPMENT.md)，实机兼容性尚未验收。
- 模型不在 DMG 内，首次使用单独下载；请预留数 GB 至十余 GB 空间，具体见安装界面。
- 当前为未公证开发预览版，不是 Mac App Store 版本，也尚未获得 Developer ID 签名。

## 安装 DMG

1. 打开[官方 Release 页面](https://github.com/Boole-Highland-Insight/AI-Everything-Public/releases/tag/v0.1.0-preview.1)，下载 `AI-Everything-0.1.0-preview.1-arm64.dmg`。
2. 双击 DMG，将 **AI Everything** 拖到 **Applications（应用程序）**。
3. 从「应用程序」打开 AI Everything，随后可推出 DMG。

如需校验文件，下载同一 Release 的 `SHA256SUMS`，将它与 DMG 放在同一目录，再在该目录打开终端运行：

```sh
shasum -a 256 -c SHA256SUMS
```

应显示 `OK`。如不一致，请停止安装并重新从官方页面下载。校验和用于核对下载完整性，不能代替 Apple 公证。

### macOS 提示无法验证开发者

未公证预览版可能被 Gatekeeper 拦截。确认下载来源与校验结果、并决定信任此应用后：

1. 尝试打开一次应用，关闭提示。
2. 前往 **系统设置 → 隐私与安全性**，找到 AI Everything 的提示。
3. 点击 **仍要打开**，按系统提示确认。

这是对此应用添加例外，无需关闭系统的全局安全保护。参考 [Apple 的官方说明](https://support.apple.com/102445)。公司管理的 Mac 可能禁止添加例外；请遵循设备管理要求。若明确提示包含恶意软件，或校验失败，请停止运行并反馈，不要绕过提示。

## 首次设置

1. **选择资料夹。** 建议先选一个小型测试资料夹。无需一次选整个磁盘，也无需授予 Full Disk Access。照片图库是可选来源，只有连接后才申请授权。
2. **查看设备与选择模型。** 三档分别为 0.6B、0.6B + 4B、0.6B + 8B。模型越大，占用和初次分析时间通常越多。可在设置中更换，已安装模型会检测并复用。
3. **可选配置云端。** 没有 OpenRouter Key 也能使用本机搜索。填入 Key 后，Jev 搜索判断会把查询和候选片段发送至云端；「咔哒一下」还会发送所选文件内容。先阅读[隐私说明](PRIVACY.md)。
4. **等待基础索引。** 文件名先可搜，OCR、向量索引和深度理解随后补齐。不要把“可以搜索”理解为全部分析结束。
5. **练习唤起。** 按 `⌥ Space` 打开搜索；快捷键冲突时也可从菜单栏进入。

## 常用操作

| 想做什么 | 怎么操作 |
|---|---|
| 搜索 | 输入文件名、关键词或内容描述 |
| 打开 / 预览 | 选中结果按 `Return` / `Space` |
| 在 Finder 中定位 | `⌘ Return` |
| 查看进度、暂停、重试 | 右上角设置 → 本机 |
| 添加或移除资料夹 | 右上角资料夹按钮 |
| 配置 OpenRouter Key | 设置 → 云端 |
| 补全或优化 | 回收入口 → 选择候选 → 咔哒一下 |
| 继续修改新版本 | 对比窗口底部输入要求 |
| 恢复文件 | 应用垃圾桶中选中文件并还原；保留期 30 天 |

## 常见问题

**搜索结果少或找不到内容**

先查看设置中的阶段进度与失败原因。文件名索引、文字识别、向量索引与深度理解不一定同时完成。移除的资料夹不会返回结果。图片描述需要内容理解模型；仅安装 0.6B 向量模型不会自动生成图片描述。

**为什么有跳过或失败**

跳过表示当前扫描阶段不处理该项，例如格式或范围不适用；失败表示已尝试但未成功。打开详情查看具体原因，可定位文件或重试失败项。它们不应被当作“成功理解”。

**模型下载失败或很慢**

检查剩余空间和网络，查看界面错误后重试；关闭应用后未完成的安装可在下次继续。安装文件有校验，网络代理或损坏下载可能导致校验失败。不要把自己的 Key 或完整下载日志贴到公开 Issue。

**本机模型占用较高**

先暂停分析，或切换到较轻方案。初次大批量扫描建议接电进行；它不是所有设备都能实时完成的任务。

**点咔哒后失败**

检查 Key、模型权限、网络和 OpenRouter 可用额度。重试云端生成可能计费。原件默认保留；生成成功也需要检查内容，不确定的建议可以点「不再推荐」。

**怎样更新**

退出应用后，将新版本拖进「应用程序」替换旧版本。本机资料和配置位于用户 Application Support，替换应用不会自动清除它们。升级前建议备份重要资料；预览版暂无自动更新承诺。

**怎样卸载或清除数据**

退出后可删除应用本身。索引、Key、模型和应用垃圾桶独立保存，见[数据位置](PRIVACY.md#本机数据在哪里)。如要清空这些数据，先还原垃圾桶里需要的文件并备份；移除资料夹只撤销搜索范围，不会立即擦除历史文本。
