# 数据与隐私边界

AI Everything 以用户选定的本机资料夹为工作范围，不要求注册应用账号，也不提供自有文件云盘。本机处理与可选云端请求的边界如下。

## 哪些内容留在本机

文件名与正文索引、系统 OCR、已安装的 Qwen3 Embedding 向量计算，以及已安装的 Qwen3-VL 内容理解都在本机进行。索引、摘要、向量、来源位置和文件反馈进入本机 SQLite 数据库。下载模型和运行时需要网络，但下载本身不需要上传资料库。

新手引导中选择本机模型方案后，即使安装失败，后台扫描也不会自动改用云端。旧开发版用户尚未选择本机方案且配置了 API 时，存在云端 QuickScan 兼容路径；建议先在设置中明确选择本机方案。该路径可能发送文本摘录、缩小图片、PDF 页面或视频抽帧。

## 哪些操作连接云端

默认服务为 OpenRouter，请求由其转发给相应模型服务。是否保留、如何处理数据由这些服务各自政策决定。

| 场景 | 发送内容 | 触发方式 |
|---|---|---|
| Jev 搜索判断 | 查询、候选文件相对路径、类型、页码与命中片段；默认每个片段最多 800 字符，每次最多 30 个候选 | 配置 Key 后自动判断常规搜索候选；精搜也会调用 |
| 咔哒一下 | 所选文件正文或图片、修改要求，按格式包含必要的页面内容 | 用户主动点击生成 |
| 继续修改与版本总结 | 当前版本、原版的必要内容及提问 | 后续修改由用户发起；生成后的对照总结可自动进行 |

云端调用可能产生费用。没有填写 Key 时，本机搜索、预览、系统 OCR 和本机模型仍可使用。Key 也可以来自 `OPENROUTER_API_KEY` 环境变量；移除界面中保存的 Key 不会清空环境变量。

蓝色上传记录并不覆盖所有历史 QuickScan 请求，因此没有上传标记不代表内容从未发送过。移除 Key 也不能撤回已经发出的请求。

## 本机数据在哪里

| 数据 | 位置 |
|---|---|
| 索引、正文块、向量、分析结果、版本关系、用户反馈 | `~/Library/Application Support/AI Everything/Index/content.sqlite` |
| OpenRouter Key | `~/Library/Application Support/AI Everything/openrouter.key`，权限 `0600`；当前尚未使用 Keychain |
| 应用垃圾桶 | `~/Library/Application Support/AI Everything/Trash/` |
| 模型与安装记录 | 用户 Application Support 下的应用运行时目录；也可能复用已有 Ollama 模型 |
| 资料夹授权书签、设置 | 当前用户 UserDefaults |
| 显式开启的调试日志 | `~/Library/Logs/AI Everything/`，默认关闭；日志可能含路径或衍生文本 |

移除资料夹后不再返回其中的搜索结果，但历史文本不会立即从数据库擦除。删除索引前应退出应用并备份。应用垃圾桶中的文件在保留期内可以还原，过期项在应用加载垃圾桶时清理；删除整个应用数据目录会同时删除这些待恢复文件。

本版本尚未实现完整 App Sandbox 隔离；不要把“本机优先”理解为操作系统强制限制了全部文件访问。

## 本公开仓库与安装包包含什么

- 公开仓库使用独立初始提交，不复制私人开发仓库的提交历史、分支或作者邮箱。
- 包含应用源码、构建工具、文档和合成演示 / 测试材料。
- 不打包个人资料库、扫描结果、聊天记录、API Key、模型权重或原开发环境缓存。
- 演示由应用界面与合成样例渲染，不录制真实桌面或私人资料夹。
- 发布检查包含密钥扫描、私人路径与已知个人标识检查、归档内容与二进制检查。检查用于降低遗漏风险，并不构成对任意未知信息的绝对保证。

发现可能泄露的信息，请通过[安全报告渠道](../SECURITY.md)私下反馈，不要在公开 Issue 中重新贴出原始内容。
